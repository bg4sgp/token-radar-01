Token Launch Radar ranks 198 pre-token protocols from a sealed DefiLlama snapshot by implied launch value: each is priced with a peer-multiple model calibrated on the live-token protocols in its own category, then adjusted for its 7-day TVL growth and for how long it has run with no token. Every row carries a concrete seven-step farm plan with costs and times, and the dashboard is a static, sortable, filterable page with a detail view per protocol and the live-token calibration set shown apart.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
